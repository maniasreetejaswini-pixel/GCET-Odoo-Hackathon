# StockSense - Inventory Management System

StockSense is a full-stack inventory management web application built with Node.js, Express, EJS, and MongoDB Memory Server.

## 🚀 Features
- **Dashboard:** Core KPIs (Total Products, Low/Out of Stock, Pending Receipts, Pending Deliveries, Internal Transfers) and Move History log.
- **Products:** Add and view products with SKU, Category, UoM, Initial Quantity, and Location tracking.
- **Operations:** Process Receipts, Delivery Orders, Internal Transfers, and Stock Adjustments in real time.
- **Settings & Profile:** Warehouse location management and profile details.

## 🛠️ Quick Start Guide for Mentors / Reviewers

No external database or MongoDB installation is required. Everything runs locally out of the box using an in-memory MongoDB server.

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Installation & Running

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/maniasreetejaswini-pixel/GCET-Odoo-Hackathon.git
   cd GCET-Odoo-Hackathon
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Application:**
   ```bash
   npm start
   ```
   *(or `node server.js`)*

4. **Access the App:**
   Open your browser and navigate to: **`http://localhost:3000`**
